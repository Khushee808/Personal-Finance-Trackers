# Personal Finance Tracker - Complete Version

## Technologies
- Python + Flask: backend and web routes
- HTML/CSS: user interface and responsive design
- JavaScript + Chart.js: interactive charts
- SQLite: local database
- openpyxl: Excel report export
- ReportLab: PDF report export

## Features
1. Login/Register with separate user data
2. Income and expense tracking
3. Expense categories
4. Dashboard summary
5. Budget limit and budget warning
6. Savings goal and savings calculation
7. Monthly reports
8. Search and filters
9. Delete transactions
10. Recurring transaction flag
11. PDF, Excel and CSV report download
12. Expense charts
13. Dark mode
14. Responsive mobile-friendly UI

## Run on Windows
Open CMD inside this project folder:

```text
pip install -r requirements.txt
python app.py
```

Then open: http://127.0.0.1:5000

Create a new account first. Set Budget and Savings Goal in Settings.
